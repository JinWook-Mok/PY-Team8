# Data Preparation

This folder contains the data preparation work for the customer churn project.

The dataset was inspected, cleaned, split into training and testing sets, encoded and scaled for further analysis.

## Folder Structure

* **Preprocessing**: Preprocessing notebook, cleaned data and validation results
* **Train_Test_Sets**: Processed training and testing datasets
* **EDA_Support**: Exploratory analysis, visualisations and summary tables
* **Documentation**: Explanations of encoding and scaling methods
