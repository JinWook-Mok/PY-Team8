# Exploratory Data Analysis Support

This folder contains exploratory data analysis and visualisations created to support the data analysis process.


## Analysis Completed

* Analysed the overall churn distribution
* Compared numerical feature distributions by churn status
* Examined correlations between numerical variables and churn
* Compared churn rates across customer categories
* Summarised important findings and practical implications

## Main Findings

* The overall churn rate was 26.54%.
* Month-to-month contract customers had the highest churn rate.
* Customers with longer contracts had lower churn rates.
* Customer tenure and monthly charges showed different patterns between churned and non-churned customers.
